# 🌸 CodeAlpha Task 1: Iris Flower Classification

This repository contains my submission for **Task 1: Iris Flower Classification** under the Data Science Internship program at **CodeAlpha**.

---

## 📌 Project Overview
The objective of this task is to train a Machine Learning model that classifies Iris flower species based on their physical measurements (sepal length, sepal width, petal length, and petal width).

  🌺 Iris Flower Species:
1. Iris-setosa
2. Iris-versicolor
3. Iris-virginica

---

📊 Dataset Information
     Name: Iris Dataset
   Features:
    `SepalLengthCm`: Sepal length in cm
    `SepalWidthCm`: Sepal width in cm
    `PetalLengthCm`: Petal length in cm
    `PetalWidthCm`: Petal width in cm
    Target Label: `Species`

---

   🛠️ Tools and Libraries Used
   Python
   Pandas: For data handling and preprocessing
   Scikit-learn: For dataset splitting and model training (Random Forest Classifier)
